Fluency tracking: Both Vocabulary and Grammar tables track times_practiced, times_correct, and a derived fluency_level (low → medium → high) based on success rates and practice frequency.

📋 Phase 1: Lesson Planning

How the system builds a level-appropriate lesson plan before the conversation begins

flowchart LR
    START(("🟢 Student
starts lesson"))
    FETCH["Fetch all known
vocab + grammar
from DB"]
    SELECT["Weighted random
selection of practice
items (prioritize low fluency)"]
    GEN["GPT-4o generates
initial lesson plan
(theme, goals, topics)"]
    REVIEW["Level Controller
reviews plan"]
    ITER{"Level appropriate?
OR iteration > 3?"}
    REFINE["Refine plan
based on feedback"]
    FINAL_PLAN["✅ Final
Lesson Plan"]
    START --> FETCH --> SELECT --> GEN --> REVIEW
    REVIEW --> ITER
    ITER -->|"NO"| REFINE --> REVIEW
    ITER -->|"YES"| FINAL_PLAN

    style START fill:#3fb950,stroke:#3fb950,color:#fff
    style FINAL_PLAN fill:#1a2e1a,stroke:#3fb950,color:#e6edf3

Adaptive planning: The system prioritizes low-fluency vocabulary and grammar for practice, then iteratively refines the lesson plan with the Level Controller to ensure it matches the student's CEFR level.

💬 Phase 2: Conversation Flow

Real-time dialogue loop from opening message through analysis and feedback

flowchart LR
    INIT["Initialize Dialogue Agent
+ Level Controller

    OPENING["Generate opening

    TTS1["🔊 Text-to-Speech

    LOOP_START{"Student

    STT["🎤 Speech-to-Text

    END_NODE(("🔴 Lesson
complete"))

    INIT --> OPENING --> TTS1 --> LOOP_START
    LOOP_START -->|"Audio"| STT --> GEN_RESP
    LOOP_START -->|"Text"| GEN_RESP
    GEN_RESP --> TTS2 --> TRANSLATE --> CHECK_END
    CHECK_END -->|"No"| LOOP_START
    CHECK_END -->|"Yes (≥15 exchanges
or [END] marker)"| END_NODE

    style INIT fill:#1a2e1a,stroke:#3fb950,color:#e6edf3

End-to-end: After the conversation ends, the system automatically extracts practiced items, runs performance analysis, updates fluency scores in the database, and returns a detailed feedback report to the student.
